# Application Layout

## Purpose

Provide one consistent layout for every application inside Banc360.

---

## Layout Zones

1. Top Navigation

2. Sidebar

3. Workspace

4. Inspector Panel (Future)

5. Status Bar

---

## Principles

- One layout
- Responsive
- No scrolling sidebar
- Workspace owns scrolling
- Navigation always visible
- Consistent spacing

---

## Future Enhancements

- Multi-monitor support
- Dockable panels
- Floating windows
