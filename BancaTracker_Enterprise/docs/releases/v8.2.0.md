# BancaTracker Enterprise v8.2.0

**Release date:** 2026-08-30  
**Theme:** Governed, durable data foundations for trusted commercial intelligence.

## Major capabilities

v8.2.0 introduces persistent governed Geography, Branch, Employee, Organisation Hierarchy, Branch Assignment, and Branch Budget & Potential masters; canonical policy-date Month/Day/FY authority; durable branch identity; assigned-RM and hierarchy resolution; governed branch-universe activation; and integrated canonical/master Data Quality readiness diagnostics.

Commercial intelligence now includes governed Performance and roll-ups, month comparison, daily premium movement, execution pacing, execution attention, execution prioritisation, structural management drill-down, and independent LOB/Product driver analysis.

## Compatibility and upgrade

The existing v8.1 analytical workflow remains available. On upgrade, IndexedDB moves to schema version 2 additively; existing stores are not intentionally cleared and active-dataset metadata persists. Upload and activate governed masters where required. Readiness can remain partial until dependencies are configured. Branch Budget/Potential is separate from legacy `target.js` session targets.

## Intentional limitations

- Organisation attribution uses the current hierarchy snapshot, not historical effective dating.
- Product/LOB identities remain transaction-derived; no Product/LOB Budget or Potential allocation is provided.
- Execution projection is simple linear pacing, not a forecast model.
- Legacy targets remain session-based and separate.
- Browser-local storage and device capacity constrain very large imports.
- Signed negative premium is preserved factually; no additional business-policy classification is imposed.
