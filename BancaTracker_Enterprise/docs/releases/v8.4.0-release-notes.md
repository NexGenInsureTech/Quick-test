# BancaTracker Enterprise v8.4.0

## Release Theme

Comparative Execution Intelligence & Operational Export

## Release Summary

v8.4.0 adds governed comparative Commercial Performance views and browser-local exports while preserving the existing offline HTML, CSS, and Vanilla JavaScript architecture.

## What’s New

### 1. Equivalent Day Pace Comparison

- Select two months and compare signed Actual through an equivalent elapsed day.
- Use the shared observed valid-transaction horizon, with an optional earlier Through Day.
- Review daily and cumulative Actual, gap, and growth in an accessible native SVG chart and detail table.
- Use governed dimensions and durable entity selection.

The observed horizon is evidence from valid dated transactions; it is not proof of complete source availability.

### 2. Branch Maturity Comparison

- Compare two months, or three months through adjacent transitions only.
- Use the existing seven maturity bands and durable branch identity.
- Review Upgraded, Unchanged, and Downgraded movements.
- Treat Zero → Active and Active → Zero as subset indicators, with Not Comparable retained separately.
- Preserve the distinction between governed zero activity and unavailable one-sided data.

### 3. Operational CSV Export

- Export Equivalent Day Comparison data.
- Export Branch Maturity Distribution data.
- Export the complete selected Branch Maturity Movement result.
- Preserve complete authority results independently of UI filters and visible-row caps.
- Generate CSV files locally in the browser without network or server dependencies.

## Architectural Guardrails Preserved

v8.4.0 does not modify `core.js`, legacy analytics, Activation, Productivity, Scorecard, Target, the CSV processor, canonical enrichment, schema/IndexedDB/repository lifecycle, masters, hierarchy/workforce authorities, Legacy Branch Assignment, or Business Attribution authority.

## Deferred / Not Included

- Average Ticket Size and policy-count KPIs.
- Historical hierarchy-as-of reconstruction.
- LOB/Product comparative scope.
- Legacy Near Active/Inactive, Productivity, or Scorecard exports.
- Grouped maturity visualization.
- New persistence, schema, or master authorities.
